# Python Roadmap (One Shot Learning)

Welcome to this Python learning repository.

This project is built as a step-by-step journey from basics to advanced concepts using Jupyter notebooks. If you are just starting out, follow the notebook order. If you already know the basics, jump directly to the topic you want to practice.

## What You Will Learn

You will cover:

- Core Python fundamentals
- Data types and operators
- Control flow and loops
- Functions and recursion
- File handling and exceptions
- OOP, lambda, generators, closures, and decorators

## How To Use This Repo

1. Clone or download this repository.
2. Open notebooks using Jupyter Notebook, JupyterLab, or VS Code.
3. Run each cell and try modifying the examples yourself.
4. Practice after each topic before moving to the next one.

## Why This Repo Is Helpful

- Short, focused notebooks
- Beginner-friendly progression
- Hands-on examples for each concept
- Useful for revision and interview prep
